Fatigue Modeling — Baselines
============================

Metrics from prior runs; refresh after re-running fatigue_modeling.ipynb.


ORDINAL BASELINES
-----------------

### global_mean

Task: Ordinal baseline (fatigue_num 0–5)
Purpose: Simplest sanity check — predict the rounded mean fatigue from training data for every row.
Optuna: None (rule-based).
Prediction: Constant integer per row; already in valid ordinal range.
Evaluation: CV and test MAE, RMSE, R2, QWK.
Limitations: Typical test MAE ~1.32 — worse than persistence baselines (lag1_fatigue ~0.93, expanding_mean ~0.84). Ignores all features and participant identity. Useful lower bound only.


### global_mode

Task: Ordinal baseline (fatigue_num 0–5)
Purpose: Predict the most frequent fatigue level in training data for every row.
Optuna: None (rule-based).
Prediction: Constant integer (mode of training target).
Evaluation: CV and test MAE, RMSE, R2, QWK.
Limitations: Typical test MAE ~0.99. Worse than lag1_fatigue and expanding_mean. Ignores features and temporal structure.


### lag1_fatigue

Task: Ordinal baseline (fatigue_num 0–5)
Purpose: Persistence benchmark — predict yesterday's fatigue for the same participant wave.
Optuna: None (rule-based prior from fatigue_lag1).
Prediction: Round prior, clip to [0, 5]; NaN priors use training fallback.
Evaluation: CV and test MAE, RMSE, R2, QWK.
Limitations: Typical test MAE ~0.93. Strong benchmark — no tuned ordinal model consistently beats it on test in prior runs. First day of each wave has NaN prior. Does not use activity features.


### expanding_mean

Task: Ordinal baseline (fatigue_num 0–5)
Purpose: Participant-wave running mean of all prior fatigue ratings (excluding current day). Smoother than lag1.
Optuna: None (rule-based prior from fatigue_expanding_mean).
Prediction: Round prior, clip to [0, 5]; NaN priors use training fallback.
Evaluation: CV and test MAE, RMSE, R2, QWK.
Limitations: Typical test MAE ~0.84 — best among ordinal baselines in prior runs. Still ignores activity features; only uses own fatigue history. Requires prior days within wave.
