Model: catboost_history
=========================

Name & Task
-----------
Registry key: catboost_history
Task type: Ordinal regression (fatigue_num, 0-5)


Purpose
-------
CatBoost on same-day features plus seven leakage-safe history columns.
Tests whether explicit fatigue/activity memory helps beat persistence baselines.


Algorithm & Library
-------------------
CatBoost with selectable ordinal loss:
  - loss_mode="rmse": CatBoostRegressor (RMSE) + clip to [0, 5]
  - loss_mode="multiclass": CatBoostClassifier (MultiClass) + expected value E[y] + clip

Wrapped in CatBoostOrdinalWrapper in src/modeling/models/ordinal.py


Source Code
-----------
Builder: build_catboost_history() in src/modeling/models/ordinal.py
History features: compute_history_features() in src/modeling/data.py
Registry: HISTORY_ORDINAL_MODELS in src/modeling/registry.py
Training data: bundle.X_train_val_history_tree / bundle.X_test_history_tree
  (rebuilt per trial with tuned ewma_alpha and rolling_window)


Input Format
------------
Tree-encoded DataFrame = make_feature_matrix() + HISTORY_FEATURES:
  fatigue_lag1, fatigue_expanding_mean, fatigue_ewma,
  active_minutes_roll3_mean, calories_sum_roll3_mean,
  very_roll3_mean, fatigue_delta_lag1


Preprocessing
-------------
Phase one-hot via build_tree_matrix().
History columns computed per participant from prior days only (shift(1)
before rolling/EWMA). First-day NaNs left missing; CatBoost handles NaN.


Default Hyperparameters
-----------------------
  iterations=300, depth=6, learning_rate=0.05, l2_leaf_reg=3.0, loss_mode="rmse"
  ewma_alpha=0.3 (EWMA_ALPHA), rolling_window=3 (ROLLING_WINDOW)


Optuna Search Space
-------------------
CatBoost: iterations [100, 500], depth [4, 10],
  learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0]
History: ewma_alpha [0.1, 0.5], rolling_window in {2, 3, 5, 7}
Loss: loss_mode in {"rmse", "multiclass"}


Training Flow
-------------
1. Each Optuna trial rebuilds history features with trial ewma_alpha / rolling_window.
2. Optuna minimizes mean CV MAE (5 GroupKFold folds by participant).
3. Fit on full train_val history tree matrix with best params; evaluate on test.


Prediction & Post-processing
------------------------------
RMSE mode: continuous prediction clipped to [0, 5].
MultiClass mode: sum(k * p_k) over classes 0-5, then clip.


Evaluation Protocol
-------------------
CV objective: MAE
Primary comparison: test MAE vs expanding_mean baseline.
Stability: run_stability_study() in src/modeling/validation.py re-tunes on
10 stratified seeds (STABILITY_SEEDS) and reports mean ± std test MAE.


Known Limitations
-----------------
History features overlap with persistence baselines; gains over expanding_mean
may be small. Stability across seeds should be checked before claiming robust improvement.
