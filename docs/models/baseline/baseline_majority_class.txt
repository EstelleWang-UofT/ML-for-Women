Baseline: majority_class
========================

Name & Task
-----------
Registry key: majority_class
Task type: Binary classification baseline (high_fatigue)


Purpose
-------
Predict the most common high_fatigue label (0 or 1) from training data for
every test row. Standard naive classifier for imbalanced binary tasks.


Algorithm & Library
-------------------
Custom sklearn estimator: MajorityClassBaseline


Source Code
-----------
Class: MajorityClassBaseline in src/modeling/baselines.py
Builder: build_majority_class_baseline()
Registry: CLASSIFICATION_BASELINES["majority_class"]
Target: high_fatigue = (fatigue_num >= HIGH_FATIGUE_THRESHOLD) where
  HIGH_FATIGUE_THRESHOLD = 4 (config.py)


Input Format
------------
Tree-encoded X_train_val_tree / X_test_tree (features ignored; row count
only matters). y is y_clf_train_val / y_clf_test.


Preprocessing
-------------
None.


Default Hyperparameters
-----------------------
None.


Optuna Search Space
-------------------
None.


Training Flow
-------------
fit(X, y):
  value_ = majority class in y
predict(X):
  constant array of value_

Evaluated via run_baseline_benchmark with task="classification".


Prediction & Post-processing
------------------------------
Integer 0 or 1 labels; no probability output.


Evaluation Protocol
-------------------
CV and test: accuracy, F1, precision, recall
Primary notebook reference for deltas: delta_*_vs_majority_class
Typical test accuracy ~0.68 (predicts negative class most often)
F1 ~0 when minority never predicted (depends on class balance)


Known Limitations
-----------------
High accuracy but zero or low F1 when minority class is rare and never
predicted. Tuned classifiers improve F1 at cost of accuracy.
Does not use any features.
