Model: catboost_residual_expanding
====================================

Name & Task
-----------
Registry key: catboost_residual_expanding
Task type: Ordinal regression (fatigue_num, 0-5) — hybrid / residual model


Purpose
-------
Hybrid model: predict deviation from the expanding-mean persistence baseline,
then add that baseline back. Used to test whether explicit residual decomposition
beats putting expanding_mean directly in the feature matrix (catboost_history).


Algorithm & Library
-------------------
pred = clip(expanding_mean + CatBoost_residual)

catboost.CatBoostRegressor (RMSE loss on residual target)
Wrapper: ResidualOrdinalWrapper in src/modeling/models/hybrid.py


Source Code
-----------
Builder: build_catboost_residual_expanding() in src/modeling/models/hybrid.py
Hybrid matrix: build_hybrid_tree_matrices() in src/modeling/data.py
Registry: RESIDUAL_ORDINAL_MODELS in src/modeling/registry.py


Input Format
------------
Tree-encoded hybrid DataFrame:
  same-day features + history columns EXCEPT fatigue_expanding_mean,
  plus __prior__ column containing the expanding mean prior for each row.


Preprocessing
-------------
History columns use prior days only (shift before rolling/EWMA).
Expanding mean prior is attached as __prior__ and excluded from CatBoost features.
CatBoost trains on residual = y - prior.


Default Hyperparameters
-----------------------
  iterations=300, depth=6, learning_rate=0.05, l2_leaf_reg=3.0
  ewma_alpha=0.3, rolling_window=3 (defaults; tuned jointly with CatBoost)


Optuna Search Space
-------------------
CatBoost: iterations [100, 500], depth [4, 10],
  learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0]
History: ewma_alpha [0.1, 0.5], rolling_window in {2, 3, 5, 7}
No loss_mode — RMSE on continuous residual only (multiclass not applicable).


Training Flow
-------------
1. Each Optuna trial rebuilds hybrid matrices with trial ewma_alpha / rolling_window.
2. ResidualOrdinalWrapper.fit: compute residuals, train CatBoost on features.
3. Optuna minimizes mean CV MAE (5 GroupKFold folds by participant).
4. Fit on full train_val; evaluate on test.


Prediction & Post-processing
------------------------------
residual_hat = CatBoost.predict(X without __prior__)
final = clip(round(prior + residual_hat))


Evaluation Protocol
-------------------
CV objective: MAE on final ordinal prediction
Compare test MAE vs expanding_mean and catboost_history.
Stability: included in run_stability_study() with 10 stratified seeds.


Known Limitations
-----------------
Underperformed catboost_history on primary split (~0.86 vs ~0.81 test MAE).
Expanding mean is already available to catboost_history as a feature; explicit
residual decomposition did not help in this dataset.
