Model: catboost_ordinal
=======================

Name & Task
-----------
Registry key: catboost_ordinal
Task type: Ordinal regression (fatigue_num, 0–5)


Purpose
-------
Gradient-boosted trees with strong tabular performance. Used here as an
ordinal regressor (RMSE loss) with clipped integer predictions.


Algorithm & Library
-------------------
catboost.CatBoostRegressor
Wrapped in OrdinalRegressorWrapper


Source Code
-----------
Builder: build_catboost_ordinal() in src/modeling/models/ordinal.py
Registry: TREE_ORDINAL_MODELS in src/modeling/registry.py
Training data: bundle.X_train_val_tree / bundle.X_test_tree


Input Format
------------
Same tree-encoded DataFrame as ordinal_rf (phase one-hot dummies).


Preprocessing
-------------
None inside CatBoost wrapper. Categorical phase already encoded as dummies
in build_tree_matrix().


Default Hyperparameters
-----------------------
loss_function = "RMSE"
iterations = 300
depth = 6
learning_rate = 0.05
l2_leaf_reg = 3.0
random_state = 42
verbose = 0


Optuna Search Space
-------------------
iterations: int, [100, 500]
depth: int, [4, 10]
learning_rate: float, log-uniform, [0.01, 0.3]
l2_leaf_reg: float, [1.0, 10.0]


Training Flow
-------------
1. Optuna minimizes mean CV MAE.
2. CatBoostRegressor.fit on full tree matrix per fold / final fit.
3. CatBoost may write catboost_info/ logs to cwd unless train_dir disabled.


Prediction & Post-processing
------------------------------
Continuous prediction clipped to [0, 5] via OrdinalRegressorWrapper.


Evaluation Protocol
-------------------
CV objective: MAE
Test metrics: MAE, RMSE, R2, QWK


Known Limitations
-----------------
Best tuned ordinal ML model in recent runs (~MAE 1.07 test) but still worse
than expanding_mean (~0.84) and lag1_fatigue (~0.93).
RMSE loss does not enforce ordinal structure.
May create catboost_info/ artifact directories during training.
