Model: ordered_logistic
=======================

Name & Task
-----------
Registry key: ordered_logistic
Task type: Ordinal regression (fatigue_num, 0–5)


Purpose
-------
All-threshold ordinal logistic regression that respects the ordered nature of
fatigue ratings. Included as a classical ordinal baseline among tuned models.


Algorithm & Library
-------------------
mord.LogisticAT (All-Threshold variant of ordinal logistic regression)
sklearn Pipeline with ColumnTransformer preprocessing


Source Code
-----------
Builder: build_ordered_logistic() in src/modeling/models/ordinal.py
Registry: ORDINAL_MODELS in src/modeling/registry.py
Training data: bundle.X_train_val / bundle.X_test (raw tabular matrix, not tree-encoded)


Input Format
------------
pandas DataFrame from make_feature_matrix() via SplitBundle:
  X_train_val, X_test with NUMERIC_FEATURES + CATEGORICAL_FEATURES


Preprocessing
-------------
ColumnTransformer inside sklearn Pipeline:
  - Numeric columns: StandardScaler
  - Categorical columns: OneHotEncoder(handle_unknown="ignore", sparse_output=False)
  - phase passed as ordered categorical in make_feature_matrix()


Default Hyperparameters
-----------------------
alpha = 1.0  (L2 regularization strength for mord.LogisticAT)


Optuna Search Space
-------------------
alpha: float, log-uniform, range [1e-3, 10.0]


Training Flow
-------------
1. Optuna minimizes mean CV MAE over 5 GroupKFold folds.
2. Best alpha refit on full train_val set.
3. model.fit(X_train_val, y_ord_train_val) — standard sklearn API.


Prediction & Post-processing
------------------------------
mord predicts integer ordinal classes directly (no clip wrapper needed).


Evaluation Protocol
-------------------
CV objective: MAE (ORDINAL_METRIC in config)
Test metrics: MAE, RMSE, R2, QWK via compute_metrics()


Known Limitations
-----------------
Tends to select high alpha (~10) under Optuna, shrinking coefficients.
Test MAE typically worse than persistence baselines (lag1_fatigue,
expanding_mean). Does not model participant-specific random effects.
