Model: lightgbm
===============

Name & Task
-----------
Registry key: lightgbm
Task type: Binary classification (high_fatigue: 1 if fatigue_num >= 4)


Purpose
-------
Gradient-boosted decision trees for detecting high-fatigue days. Primary
tuned classifier; handles class imbalance via balanced class weights.


Algorithm & Library
-------------------
lightgbm.LGBMClassifier (objective="binary")


Source Code
-----------
Builder: build_lightgbm_classifier() in src/modeling/models/classification.py
Registry: CLASSIFICATION_MODELS in src/modeling/registry.py
Training data: bundle.X_train_val_tree / bundle.X_test_tree


Input Format
------------
Tree-encoded DataFrame (build_tree_matrix): numeric features plus
phase one-hot dummy columns.


Preprocessing
-------------
None inside the model. Phase encoding handled in build_tree_matrix().


Default Hyperparameters
-----------------------
objective = "binary"
class_weight = "balanced"
n_estimators = 200
max_depth = -1  (no limit; Optuna searches positive depths)
learning_rate = 0.05
num_leaves = 31
min_child_samples = 20
random_state = 42
verbose = -1


Optuna Search Space
-------------------
n_estimators: int, [100, 500]
max_depth: int, [3, 12]
learning_rate: float, log-uniform, [0.01, 0.3]
num_leaves: int, [15, 63]
min_child_samples: int, [5, 50]


Training Flow
-------------
1. Optuna maximizes mean CV F1 (CLASSIFICATION_METRIC).
2. Standard sklearn fit/predict on tree matrix.
3. Default threshold 0.5 for binary class assignment at predict time.


Prediction & Post-processing
------------------------------
model.predict() returns 0/1 labels (LightGBM default threshold).
No custom threshold tuning in current pipeline.


Evaluation Protocol
-------------------
CV objective: F1 (pos_label=1)
Test metrics: accuracy, F1, precision, recall
Delta vs majority_class: positive delta on F1 means improvement


Known Limitations
-----------------
High recall (~0.65–0.87) but low precision (~0.29–0.30) on test.
Test accuracy (~0.32–0.39) below majority_class (~0.68) because
minority class is rare and model favors positive predictions.
Beats majority baseline on F1 but not on accuracy.
