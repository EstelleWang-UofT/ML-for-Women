Model: random_forest
=====================

Name & Task
-----------
Registry key: random_forest
Task type: Binary classification (high_fatigue: 1 if fatigue_num >= 4)


Purpose
-------
Ensemble of bagged decision trees for high-fatigue detection. Simpler
nonlinear alternative to LightGBM with balanced class weights.


Algorithm & Library
-------------------
sklearn.ensemble.RandomForestClassifier


Source Code
-----------
Builder: build_rf_classifier() in src/modeling/models/classification.py
Registry: CLASSIFICATION_MODELS in src/modeling/registry.py
Training data: bundle.X_train_val_tree / bundle.X_test_tree


Input Format
------------
Tree-encoded DataFrame from build_tree_matrix() (same as lightgbm).


Preprocessing
-------------
None inside the model.


Default Hyperparameters
-----------------------
class_weight = "balanced"
n_estimators = 300
max_depth = None
min_samples_leaf = 1
max_features = "sqrt"
random_state = 42
n_jobs = -1


Optuna Search Space
-------------------
n_estimators: int, [100, 500]
max_depth: int, [3, 20]
min_samples_leaf: int, [1, 10]
max_features: categorical ["sqrt", "log2"]


Training Flow
-------------
1. Optuna maximizes mean CV F1.
2. RandomForestClassifier.fit on tree-encoded train_val matrix.
3. predict() returns hard 0/1 labels.


Prediction & Post-processing
------------------------------
Standard sklearn binary predictions; no probability threshold tuning.


Evaluation Protocol
-------------------
CV objective: F1
Test metrics: accuracy, F1, precision, recall
Notebook delta columns: delta_*_vs_majority_class


Known Limitations
-----------------
Similar trade-off to LightGBM: better F1 than majority class, worse
accuracy. Low precision on high-fatigue class due to class imbalance.
No participant-level grouping in the forest itself (only in CV splits).
