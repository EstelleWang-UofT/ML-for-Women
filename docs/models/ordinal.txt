Fatigue Modeling — Ordinal Models
===================================

All models target fatigue_num (0–5) and are evaluated with task='ordinal' (MAE, RMSE, R2, QWK).
Refresh metrics after re-running fatigue_modeling.ipynb.


ORDINAL REGRESSION
------------------

Continuous loss on the numeric fatigue scale; predictions are rounded and clipped to [0, 5].


### linear_regression

Task: Ordinal regression (fatigue_num 0–5)
Purpose: Ridge regression baseline on scaled numeric + one-hot categorical features.
Optuna: alpha log-uniform [1e-3, 10.0].
Prediction: clip(round(ŷ), 0, 5).
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: Linear structure; no tree interactions.


### ordinal_rf

Task: Ordinal regression (fatigue_num 0–5)
Purpose: Random forest regressor on tree-encoded features; treats ordinal target as continuous.
Optuna: n_estimators [100, 500], max_depth [3, 20], min_samples_leaf [1, 10].
Prediction: Regressor output rounded and clipped to [0, 5].
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: No monotonicity constraint across classes.


### catboost_regressor

Task: Ordinal regression (fatigue_num 0–5)
Purpose: CatBoost gradient boosting with RMSE loss on tree-encoded features.
Optuna: iterations [100, 500], depth [4, 10], learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0].
Prediction: Continuous output clipped to [0, 5].
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: RMSE loss does not enforce ordinal class structure.


ORDINAL CLASSIFICATION
----------------------

Ordered likelihood or cumulative-threshold structure on fatigue_num 0–5.


### ordered_logistic

Task: Ordinal classification (fatigue_num 0–5)
Purpose: All-threshold ordinal logistic regression (mord LogisticAT).
Optuna: alpha log-uniform [1e-3, 10.0].
Prediction: Integer ordinal classes directly from mord.
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: Tends to select high alpha under Optuna. No participant random effects.


### ordinal_forest

Task: Ordinal classification (fatigue_num 0–5)
Purpose: Cumulative-threshold random forest ensemble (five P(y > k) binary forests).
Optuna: n_estimators [100, 500], max_depth [3, 20], min_samples_leaf [1, 10].
Prediction: Class probabilities from threshold survival function; expected class clipped to [0, 5].
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: Five binary models per fit; threshold probabilities enforced monotonic at predict time.


### mixed_effects

Task: Ordinal classification (fatigue_num 0–5)
Purpose: Population-level ordered logistic model on day-varying covariates (not a true mixed-effects model).
Optuna: maxiter [200, 800].
Prediction: Argmax over class probabilities (integer 0–5).
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: Misleading registry name — no random effects for participants. Ignores static demographics. Convergence not guaranteed.


### catboost_ordinal

Task: Ordinal classification (fatigue_num 0–5)
Purpose: CatBoost MultiClass with balanced class weights; expected value E[y] over class probabilities.
Optuna: iterations [100, 500], depth [4, 10], learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0].
Prediction: E[y] from predict_proba, then clip to [0, 5].
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.
Limitations: MultiClass loss is nominal; order respected at prediction time via expected value.


HISTORY / HYBRID ORDINAL MODELS
-------------------------------

### catboost_history

Task: Ordinal regression (fatigue_num 0–5)
Purpose: CatBoost on same-day features plus seven leakage-safe history columns.
Optuna: CatBoost iterations [100, 500], depth [4, 10], learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0]; history ewma_alpha [0.1, 0.5], rolling_window {2, 3, 5, 7}; loss_mode {rmse, multiclass}.
Prediction: RMSE mode — continuous output clipped to [0, 5]. Multiclass mode — expected value E[y] over classes 0–5, then clip.
Evaluation: CV MAE. Test MAE, RMSE, R2, QWK.


### catboost_residual_expanding

Task: Ordinal regression (fatigue_num 0–5) — hybrid / residual model
Purpose: Predict deviation from expanding-mean persistence baseline, then add baseline back.
Optuna: CatBoost iterations [100, 500], depth [4, 10], learning_rate log-uniform [0.01, 0.3], l2_leaf_reg [1.0, 10.0]; history ewma_alpha [0.1, 0.5], rolling_window {2, 3, 5, 7}. RMSE on residual only.
Prediction: clip(round(expanding_mean_prior + CatBoost_residual), 0, 5).
Evaluation: CV MAE on final ordinal prediction. Test MAE, RMSE, R2, QWK.
