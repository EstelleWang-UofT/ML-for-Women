**To use mcPHASES:**

1. Download the mcPHASES dataset locally from https://www.physionet.org/content/mcphases/1.0.0/, then add it locally to the mcphases/ folder. This is because the raw dataset is too large to be stored in GitHub.
2. mcphases/merged will store the merged datasets, so you need to run all Python scripts in src/ to generate full merged datasets. They are also stored locally
3. notebook/ is to store Jupyter notebooks. Currently, this folder contains the data exploration notebook.
