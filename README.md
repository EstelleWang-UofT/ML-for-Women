**To use mcPHASES:**

1. Download the mcPHASES dataset locally from https://www.physionet.org/content/mcphases/1.0.0/, then add it locally to the mcphases/ folder. This is because the raw dataset is too large to be stored in GitHub.
2. mcphases/merged only contains the merged datasets that are less than 100mb, so it's best to run all Python scripts in src/ to generate full merged datasets.
3. notebook/ is to store Jupyter notebooks. Currently, this folder contains the data exploration example/template.
